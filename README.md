# 🔐 Encryption & Decryption Tool

A Python-based encryption and decryption application designed to demonstrate the fundamentals of cryptography, secure data handling, and information protection.

## 📌 Project Overview

The Encryption & Decryption Tool is a program that allows users to convert readable information (plaintext) into an unreadable format (ciphertext) and restore encrypted information back to its original form.

The project demonstrates how cryptographic techniques help protect sensitive information from unauthorized access.

## ⚙️ Features

- **Text Encryption:** Converts plaintext into encrypted ciphertext.
- **Text Decryption:** Restores encrypted text to its original form.
- **Data Protection:** Helps prevent unauthorized access to readable information.
- **User-Friendly Interface:** Simple interaction for encryption and decryption operations.
- **Python Implementation:** Developed using Python programming.

## 🛠️ Technologies Used

- Python 3.x
- Cryptography
- Command-Line Interface (CLI)

## 🔍 How It Works

The programme follows two fundamental processes:

**Encryption Process**

1. The user enters readable text.
2. The programme processes the input using an encryption algorithm.
3. The original text is converted into ciphertext.
4. The encrypted output is displayed.

**Decryption Process**

1. The user provides the encrypted text.
2. The programme applies the corresponding decryption process.
3. The ciphertext is converted back into plaintext.
4. The original message is displayed.
